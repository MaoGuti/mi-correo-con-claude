Política de privacidad

Última actualización: 30 de septiembre de 2026

Esta política describe cómo la aplicación Mi correo con Claude trata los datos a los que accede. La aplicación es una herramienta personal de un solo usuario, ejecutada localmente en el computador de su autor.

Quién es el responsable

El autor de la aplicación, persona natural. Contacto: github.com/MaoGuti

A qué datos accede la aplicación

Con la autorización explícita del usuario mediante OAuth 2.0 de Google, la aplicación puede acceder a:

  • Mensajes, etiquetas y configuración básica de Gmail
  • Eventos de Google Calendar
  • Archivos de Google Drive
  • Contenido de documentos de Google Docs y hojas de Google Sheets
  • La dirección de correo asociada a la cuenta, para identificar la sesión

El único usuario cuyos datos se procesan es el propio autor de la aplicación, sobre su propia cuenta de Google.

Para qué se usan

Exclusivamente para ejecutar las acciones que el usuario solicita en el momento: leer o enviar un correo, consultar o crear un evento, abrir o modificar un archivo. No se usan para publicidad, perfilado, analítica ni para entrenar modelos de inteligencia artificial.

Dónde se almacenan

La aplicación no opera servidores propios ni bases de datos remotas. El único dato que se guarda de forma persistente es el token de acceso de Google, almacenado en el computador local del usuario para no tener que autorizar la aplicación en cada ejecución. El contenido de correos, archivos y eventos se mantiene en memoria durante la ejecución y no se conserva después.

Con quién se comparten

Con nadie. No se venden, alquilan ni transfieren datos a terceros. La comunicación ocurre únicamente entre el computador del usuario y los servidores de Google.

Cuando el usuario utiliza la aplicación junto con un asistente de inteligencia artificial, el contenido que el usuario decide enviarle se procesa conforme a las políticas de privacidad de ese proveedor. Esa transmisión solo ocurre por acción deliberada del usuario.

Uso limitado de los datos de Google

El uso que esta aplicación hace de la información recibida de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado.

Cómo revocar el acceso

El usuario puede retirar la autorización en cualquier momento desde la página de permisos de su cuenta de Google. Al hacerlo, el token almacenado deja de ser válido de inmediato. Borrar el archivo del token en el computador local tiene el mismo efecto.

Seguridad

Las credenciales y el token se guardan en el sistema de archivos del computador del usuario y quedan protegidos por los controles de acceso de ese equipo. Toda la comunicación con Google ocurre sobre HTTPS.

Menores de edad

La aplicación no está dirigida a menores de edad ni recoge datos de ellos.

Cambios

Si esta política cambia, la nueva versión se publicará en esta misma página con su fecha de actualización.
